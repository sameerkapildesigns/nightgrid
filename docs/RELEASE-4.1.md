# R4.1, included in the combined R5 release

The menu, inward visual lean, permanent shared arrows, aligned pad bounds, solo Next map and JSON snapshot fixes were first prepared as R4.1. That candidate was held and was not shipped separately.

The later instruction was to deliver everything in one paired release. R5 includes those fixes plus comfort, driving balance, traffic, sound, exhaust flames, rival randomization, four circuit redesigns and optional jump rolls.

See [RELEASE-5.md](RELEASE-5.md) for the current changes, verification, limits and deployment requirements. Old R4.1-only route descriptions, record-key plans and held feedback are superseded. Kage and Legacy geometry remain exactly R4; all maps use isolated R5 records because the shared driving physics changed.
